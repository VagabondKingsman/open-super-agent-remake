# i18n (vi / en / zh)

Added on branch `i18n-vi` (OSA v0.5.0). Stable translation keys; do not hardcode find-replace Chinese in components.

## Frontend
- Library: `i18next` + `react-i18next`
- Packs: `web/src/locales/{vi,en,zh}/common.json`
- Bootstrap: `web/src/i18n.ts` (default **vi**, fallback zh → en)
- Switch language: **Settings → Data → Language**, or `localStorage.osa.locale`

MVP covered: Onboarding, Sidebar, Settings shell (nav/titles/limits) + Language page, Chat chrome (thinking/copy/approvals/task cards), Composer placeholders/hints.

Still Chinese (next passes): Market, Library, ModelSettings forms, Channels, Backup, BotEditor, Groups, Templates catalog text, many system message markers from the server.

## Backend
- Env: `OSA_LOCALE=vi|en|zh` (default vi)
- Module: `osa/i18n.py`
- Packs: `osa/locales/{vi,en,zh}/__init__.py` — `ROUTER_PROMPT`, `WORKER_PROMPT`, `GROUP_PROMPT`, DM/REPLY blocks, approval/`settings.problem` short strings

## Run
```bash
cd /workspace/open-super-agent
cp -n .env.example .env   # set OSA_LOCALE=vi
(cd web && npm ci && npm run build)
OSA_LOCALE=vi uv run uvicorn osa.server:app --host 127.0.0.1 --port 8765
# open http://127.0.0.1:8765
```
