# AI vocabulary and phrases

Lookup table for the rules in `SKILL.md`. The best fix is usually the specific fact, not a synonym. One word from this list is not automatically wrong. It becomes a tell when it stands in for a fact, when it clusters with others, or when it repeats.

## 1. Rule 7: words

| Word | Use instead |
|---|---|
| additionally, furthermore, moreover | also, and, or nothing |
| crucial, pivotal, vital, essential (as praise) | important, or say what depends on it |
| delve (into) | look at, explain, cover |
| enhance, elevate | improve, raise (with the number) |
| foster, cultivate | build, encourage, help |
| garner | get, win |
| interplay | how X and Y affect each other |
| intricate, nuanced | complex, or name the parts |
| landscape, realm, sphere (abstract) | market, field, or drop |
| showcase | show |
| tapestry | drop the metaphor |
| testament (to) | shows, proves |
| underscore, highlight (verb) | show, point to |
| vibrant, dynamic, bustling | describe what's there |
| robust | reliable, handles X |
| seamless, frictionless | name the steps it removes |
| comprehensive, holistic | full, or list the scope |
| cutting-edge, state-of-the-art | new, or name the technique |
| innovative, revolutionary, groundbreaking | new, first, or say what changed |
| streamline | simplify, cut steps (how many) |
| empower, enable (as praise) | let, allow, help |
| unlock | get, open, allow |
| harness, leverage | use |
| navigate (abstract) | handle, deal with |
| embark | start |
| meticulous, meticulously | careful, or describe the care |
| paramount | most important |
| myriad, plethora | many |
| bespoke, tailored | custom, made for |
| synergy | describe the combined effect |
| actionable (insights) | name the action |
| elevate your X | improve X by Y |
| boost | increase (by how much) |
| journey (abstract) | process, time, steps |

## 2. Rule 7: phrases

| Phrase | Fix |
|---|---|
| plays a crucial / pivotal / key role in | say what it does |
| in today's fast-paced / ever-evolving world | delete |
| a game-changer | say what changed |
| a deep dive into | a close look at, or just the topic |
| the power of X | X |
| take X to the next level | improve X by Y |
| stands out as | is |
| a wide range of / a variety of | many, or list them |
| look no further | delete |
| whether you're a beginner or a pro | name the actual reader |
| it's no secret that | delete |
| the ever-changing landscape | delete |
| unlock the full potential of | use X fully, or say how |
| navigate the complexities of | handle X |
| a testament to | shows |
| ever-evolving, ever-growing | growing (by how much) |

## 3. Rule 8: fancy "is"

serves as, stands as, acts as (when nothing acts), functions as, represents, boasts, features, offers (for "has"), is home to, comes equipped with. Use "is" or "has".

## 4. Rules 3, 9, 12: sentence frames

| Frame | Fix |
|---|---|
| …, highlighting / emphasizing / showcasing / reflecting X | delete the tail, or make it a sentence with evidence |
| …, ensuring / allowing / enabling X | say how, in its own sentence |
| …, contributing to X | delete or give the result |
| It's not just X, it's Y / Not only X but also Y | state Y |
| X isn't about Y. It's about Z. | state Z |
| More than just X | delete the frame |
| From X to Y (unrelated ends) | list the real cases |
| Whether X or Y, … | name the actual reader |

## 5. Rules 20, 22, 25: chatbot and empty endings

Delete: I hope this helps; Let me know if you have any questions; Feel free to reach out; Happy coding!; Let's dive in; Let's explore; Buckle up; Without further ado; Great question; You're absolutely right; Certainly; Absolutely!; In conclusion; To sum up; In summary; Ultimately; At the end of the day; The future looks bright; The possibilities are endless; Only time will tell; Embrace the future; Stay tuned.

## 6. Rules 23, 24, 30, 31: filler and inflated words

| Phrase | Fix |
|---|---|
| in order to | to |
| due to the fact that | because |
| at this point in time | now |
| it is important to note that | delete |
| it's worth noting / mentioning that | delete |
| when it comes to X | for X, or make X the subject |
| in terms of | for, in, or rewrite |
| the fact that | that, or rewrite |
| a number of | some, several, or the number |
| could potentially | could |
| may possibly | may |
| it could be argued that | delete or argue it |
| really, truly, incredibly, extremely, highly | delete or use a number |
| significantly, dramatically, substantially | the measured change |
| utilize, leverage | use |
| facilitate | help |
| commence, initiate | start |
| endeavor | try |
| ascertain | find out |
| numerous | many |
| prior to | before |
| subsequently | then, later |
| in the event that | if |

## 7. Rules 26, 32: metaphor and mannered prose

Metaphor nouns: north star, flywheel, moat, lever, bedrock, cornerstone, building blocks, backbone, linchpin, secret sauce, silver bullet, low-hanging fruit, double-edged sword, the elephant in the room, a perfect storm, uncharted waters.

Mannered moves: one-line paragraphs for drama ("And that changes everything."), rhetorical questions answered at once ("The result? A faster site."), personified software ("the tool knows what you need"), stacked fragments ("Simple. Fast. Reliable."), aphorisms ("Ship it or kill it.").
